# Golden Compass

A mobile investment-app prototype exploring portfolio dashboards, investment pools, transaction history, identity verification, and an AI-assisted financial navigation experience.

The React Native application is located in the `golden-compass/` directory.

## Features

- Investor dashboard and portfolio overview
- Investment pool browsing and detail screens
- Transaction history and profile screens
- KYC flow and administrative dashboard
- AI Navigator interface

## Technology

- React Native and Expo
- Expo Router
- TypeScript
- Zustand
- React Native SVG and charting components

## Getting Started

Requirements: Node.js, npm, and the Expo development environment.

```bash
cd golden-compass
npm install
npx expo start
```

Use the Expo development tools to launch the app on Android, iOS, or the web.

## Important

This repository is a prototype. Authentication, payment flows, AI responses, and other service-dependent features may use local or simulated behaviour. It is not a live investment or brokerage service.
