# Golden Compass — React Native Prototype

A mobile investment-app prototype exploring portfolio dashboards, investment pools, transaction history, identity verification, and an AI-assisted financial navigation experience.

## Features

- Investor dashboard and portfolio overview
- Investment pool browsing and detail screens
- Transaction history and profile views
- KYC flow and administrative dashboard
- AI Navigator interface

## Technology

React Native · Expo SDK 52 · Expo Router · TypeScript · Zustand

## Getting Started

Requirements: Node.js, npm, and the Expo development environment.

```bash
npm install
npx expo start
```

Use the Expo development tools to launch the app on Android, iOS, or the web.

## Project Status

This is a prototype. Authentication, payment flows, AI responses, and other service-dependent features may use local or simulated behaviour. It is not a live investment or brokerage service.
